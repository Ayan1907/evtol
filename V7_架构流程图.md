### A.4 能量叠加公式(修正)

**简化模型(错误❌)**:
```
L_total = L_source - L_geo - L_atm + L_gr - L_occ  ← 分贝不能直接加减！
L_add = L_1 + L_2 + L_3  ← 声学错误！能量叠加≠分贝相加
```

**改进模型(正确✅)**:
```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           能量叠加四步法                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Step 1: 各衰减项转能量比                                                    │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  g_spread = 10^(-L_geo / 10)    ← 几何扩散能量比                     │   │
│  │  g_atm    = 10^(-L_atm / 10)    ← 大气吸收能量比                     │   │
│  │  g_ground = 10^(L_gr  / 10)     ← 地面效应能量比(可能<1)            │   │
│  │  g_occ    = 10^(-L_occ / 10)    ← 建筑遮挡能量比                     │   │
│  │  g_dir    = 10^(-L_dir / 10)    ← 指向性能量比                       │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Step 2: 能量乘积叠加                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  G_total = g_spread × g_atm × g_ground × g_occ × g_dir           │   │
│  │                                                                       │   │
│  │  物理意义: 声音从声源到接收点，各衰减机制的能量传递效率乘积            │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Step 3: 转回分贝                                                           │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  L_total = L_source + 10 × log10(G_total)                          │   │
│  │                                                                       │   │
│  │  推导:                                                               │   │
│  │    L_total = 10 × log10(I_total / I_ref)                           │   │
│  │            = 10 × log10(I_source × G_total / I_ref)                │   │
│  │            = L_source + 10 × log10(G_total)                        │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### A.5 完整噪声传播模型

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        eVTOL 噪声传播完整公式                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  L_total = L_source + 10·log₁₀(G_total)                                    │
│                                                                             │
│  其中 G_total = G_geo × G_atm × G_ground × G_occ × G_dir                  │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 1. 几何扩散 G_geo = (d_ref / d)²                                     │ │
│  │    • d_ref = 100m (参考距离)                                          │ │
│  │    • d = √(x² + y² + z²) (斜距)                                      │ │
│  │    • 球面扩散：距离每翻倍，衰减6dB                                      │ │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│  │ 2. 大气吸收 G_atm = 10^(-α·d / 10)                                   │ │
│  │    • α = f(T, RH, f)  (ISO 9613-1 Table)                             │ │
│  │    • 125Hz: 0.3dB/km, 1kHz: 2.5dB/km, 4kHz: 11dB/km                 │ │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│  │ 3. 地面效应 G_ground                                                  │ │
│  │    • 硬地面(G=0): 无反射                                               │ │
│  │    • 草地(G=2): 轻微反射                                               │ │
│  │    • 水面(G=1): 中等反射                                               │ │
│  │    • L_ground = -A·G·h/d  (h < d时适用)                              │ │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│  │ 4. 建筑遮挡 G_occ = 10^(-L_diff / 10)                                 │ │
│  │    • L_diff = 5·(1 - e^(-N))  (Fresnel衍射)                         │ │
│  │    • N = 2δ/λ (Fresnel参数)                                          │ │
│  │    • δ ≈ h²/(2d) (路径差)                                             │ │
│  ├───────────────────────────────────────────────────────────────────────┤ │
│  │ 5. 指向性 G_dir = 10^(-Q(θ) / 10)                                     │ │
│  │    • Q(θ): 角度θ方向的指向性衰减                                       │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### A.6 PPT中的错误方程对照

| PPT原文(错误❌) | 正确形式✅ | 问题说明 |
|--------------|----------|----------|
| `L_atm = 3dB/km × d/1000` | `L_atm = α(f) × d / 1000` | 吸收率应为频率依赖的α(f)∈[0.3,25]，非固定3dB/km |
| `L_total = SL - 20log(d) - L_atm + L_gr - L_occ` | `L_total = SL + 10log10(Πg_i)` | 分贝不能线性加减，需能量叠加 |
| `L_add = L_1 + L_2 + L_3` | `L_add = 10log10(Σ10^(L_i/10))` | 多声源叠加需能量叠加公式 |
| `L_ground = 10log(h/√(h²+d²))` | `L_ground = G ∈ [-6, +4] dB` | 地面效应为材质依赖的G值，非此公式 |
