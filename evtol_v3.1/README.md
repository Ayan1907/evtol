# eVTOL Path Planning V3.1 备份版本

## 版本说明

本版本为V3算法的完整备份，整合了低碳优化算法和18方向路径搜索。

## 文件清单

### 核心算法文件
- `evtol_path_planning_v3.py` - 主程序，整合低碳A*算法和18方向搜索
- `low_carbon_astar.py` - 低碳A*算法实现
- `low_carbon_node.py` - 低碳节点类和指标计算

### 地图文件
- `test_map_v3_compatible.json` - V3兼容的测试地图

### 结果文件
- `evtol_v3_results/v3_path_comparison_2d.png` - 2D路径对比图
- `evtol_v3_results/v3_path_3d_Low-Carbon Balanced.png` - 3D路径图

### 文档文件
- `evtol_v3_README.md` - V3版本说明文档
- `低碳A*算法说明.md` - 低碳A*算法详细说明
- `V3版本总结.md` - V3版本开发总结

## 算法特点

1. **多目标优化**: G = α₁·L + α₂·E + α₃·Σ|Δh| + α₄·Σ|Δβ| + H·(ω₁ + ω₂)
2. **18方向搜索**: 6个基本方向 + 12个对角方向
3. **自适应方向切换**: 距离<100m时切换到6方向
4. **弱启发函数**: h × 0.5，让g值主导搜索
5. **250栋建筑物**: 保持与V2一致的高密度建筑环境

## 配置方案

- **Shortest Path**: α=(1,0,0,0), ω=(0,0)
- **Low-Carbon Balanced**: α=(0.4,0.4,0.1,0.1), ω=(0.5,0.5)
- **Low-Carbon Smooth**: α=(0.3,0.3,0.2,0.2), ω=(0.7,0.3)

## 关键参数

- 步长: 水平20m, 垂直10m
- 最大迭代: 200,000
- 建筑数量: 250栋
- 起始/终点保护区: 100m半径

## 测试结果

Shortest Path配置：
- 迭代次数: 44,346
- 转角总和: 7.07 rad
- 垂直变化: 20m

Low-Carbon配置：
- 迭代次数: ~250
- 转角总和: 10.21 rad
- 垂直变化: 60m
