# eVTOL路径规划V7版本说明

## 版本概述

V7版本基于V6+修复**HV计算基准变化**导致的跨代数不可比问题，并增强多目标优化能力：

1. **【关键修复】HV固定参考点** - 解决跨代数HV不可比问题
2. **增强多目标优化** - 自适应停滞检测 + 变异效果跟踪
3. **目标归一化支持** - 处理不同量级的目标函数
4. 保持V6+所有功能完整

---

## V7核心改进

### 🔴 问题: HV计算基准变化

#### 问题描述
V6/V6+版本中，`_calculate_hypervolume` 函数使用**动态参考点**：

```python
# V6 - 有问题的设计
reference_point = np.max(obj_matrix, axis=0) * 1.1 + 0.1  # 动态参考点
```

这导致：
- Pareto质量变化 → 参考点变化 → HV "看起来"变化
- 无法准确比较不同代数之间的真实Pareto前沿质量
- HV值骤降35倍的异常现象

#### V7的修复

```python
# V7 - 修复后
# 第一代: 使用当前最大值 * 1.2 作为固定参考点
if len(self.objective_ranges_history) == 1:
    self.fixed_reference_point = obj_maxs * 1.2
```

**修复效果**:

| 指标 | V6修复前 | V7修复后 |
|------|----------|----------|
| HV量级 | 248,575~924,502 | ~11,000,000 |
| 跨代可比性 | 不可比（动态参考点） | 可比（固定参考点） |
| HV骤降现象 | 有 | 无 |

## 总结

V7版本通过修复**HV计算基准变化**这一关键问题，使多目标优化的收敛监控恢复正常：

1. HV固定参考点 - 确保跨代数可比性
2. 自适应停滞检测 - 自动调整优化参数
3. 变异效果跟踪 - 可观测遗传算子效果
4. 增强可视化 - 综合仪表盘展示

V7完全保留了V6+的所有功能，只修复了HV计算问题并增强了优化器，适合作为正式版本使用。
